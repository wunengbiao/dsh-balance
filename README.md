# dsh-balance

侧栏底部的一张余额卡片，替代原来的 `··· 更多` 账户入口。余额用已配置的
DeepSeek API Key 读取，**不需要登录账号**。卡片同时收拢了侧栏顶部那些零散入口，
把「新会话 / 插件 / 更多 / 导入会话」四行从顶部移走，换上三个图标。

## 安装

在 DSH 的 **插件 → 添加插件** 里填 GitHub 规格：

```
github:wunengbiao/dsh-balance#v1.0.0
```

或直接指向本地目录。装完在插件列表启用即可，侧栏底部就是这张卡。

## 卡片长这样

```
● BALANCE · 余额                 ⚙
¥1,143.52
────────────────────────────────
⬆  ✿  ☀  ⋯          ( 💬 | <> )
```

杂志式排版：大写小标签压住视线、金额放大到 26px 成主体、一条细分隔线把「读」和「点」分开；
底部左侧是工具、右侧是图标按键式的模式切换（对话 / 写代码）。

- **● 状态点**：绿点 `state-success`；余额低于 1 或读取失败时变 `state-warn`，和金额变色同一判据。
- **余额**：宿主侧解析 `DEEPSEEK_API_KEY` → `GET /user/balance` → 60 秒缓存。点金额强制刷新。
- **导入会话（⬆）**：代点内置导入器的触发器（它没有对外服务），弹窗仍由它自己管理。
- **插件（✿）**：打开「插件」面板，并把顶部那一行「插件」隐藏。
- **主题（☀/☾）**：调 `ctx.theme.setTheme()`，与 设置 → 外观 同一条路径，会持久化。
- **设置（⚙）**：打开设置面板；`Cmd+,` 由内置 Settings 自己处理，不经过本插件。
- **模式切换（💬 / <>）**：底部胶囊里两个按键，镜像 `dsh-plugin-chat` 的 `.dpc-seg`；它没装时不显示。
- **更多（⋯）**：向上弹出侧栏面板列表（自动化任务、上下文洞察……），并把顶部那一行「更多」隐藏。
  菜单项来自实时的 `sidebar.panellist` 注册，不写死；用内置 `Menu` 渲染。

## 表面

卡片不是一块白/黑实色，而是 `layer-1 → sidebar-fill` 的竖向渐变，顶部离底、底部融进侧栏，
配一条 `border-l2` 细描边加 1px 内高光。这样在浅色和暗色下都不会出现"贴了一块板"的割裂感。

## 顶部被移走的东西

| 原位置 | 现在 | 实现方式 |
|---|---|---|
| 「新会话」整行 | 移除 | 隐藏 `_newSessionRow`；品牌行、工作区 `＋`、折叠态 `＋` 仍可新建 |
| 「插件」行 | 卡片 ✿ | 按 8 种语言的标签匹配隐藏 |
| 「更多」行 | 卡片 ⋯ | 按 `aria-haspopup="menu"` 语义选择器隐藏 |
| 「导入会话」按钮 | 卡片 ⬆ | 按 8 种语言的标签匹配隐藏，卡片代点其触发器 |
| 面板导航整块 | 卡片 ⋯ | 顶部因此不再有空白带 |
| 输入框的模式切换 | 卡片 💬/<> | 隐藏 `.dpc-mode`，卡片按索引点它自己的 `.dpc-seg` |

这些隐藏都在 `:root:has(.dshb-card)` 作用域内 —— 卡片不在（折叠成轨道、侧栏隐藏、插件停用）时，
原样恢复。

## 为什么这样接管

底部那一行不是独立按钮，它是 `dsh-client-ui-settings-account` 注册进
`settings.launcher` 的账户启动器（未登录时显示三颗点 +「更多」）。本插件用更低的
`priority` 覆盖这**一个座位**：

- 设置面板、`Cmd+,`、面板导航、`sidebar.settings` 座位仍归内置包，不动；
- 停用插件后原启动器原样回来。

## 折叠态

56px 轨道里退化为 36px 卡片图标：右下角 5px 状态点（`state-success` / `state-warn`），
金额只在 tooltip 里出现。未配置 Key 时图标用虚线描边。

## 数据与状态

| 状态 | 表现 |
|---|---|
| 正常 | 金额 |
| 余额低于 1 | 金额变 warn 色，右侧「余额不足」 |
| 未配置 API Key | 「未配置 API Key」+「去设置」，**不显示 0** |
| 读取失败 | 有旧值时保留旧金额 +「重试」；没有旧值时「暂时读不到余额」 |
| 首次读取 | 骨架条 |

点击金额强制刷新；窗口重新聚焦、每 5 分钟也会刷新一次。

## 接口

`GET /dsh-balance/v1/balance[?refresh=1]`

```json
{ "ok": true, "configured": true, "keyEnv": "DEEPSEEK_API_KEY", "isAvailable": true,
  "wallets": [{ "currency": "CNY", "total": "1741.77", "granted": "0.00", "toppedUp": "1741.77" }],
  "fetchedAt": "2026-11-25T13:56:28.388Z" }
```

路径带版本号：重载后旧激活留下的路由不会和新代码抢同一条路径（服务端拒绝同路径重复注册）。

## 限制

- DeepSeek 余额接口只有 `total_balance` / `granted_balance` / `topped_up_balance`，没有按天、
  按月的消费金额，DSH 的 token 计量也明确声明「不是计费输入」。因此本卡片**不显示也不估算消费金额**。
- 隐藏顶部「插件」行是按可访问名称匹配当前 8 种语言的标签，且只在卡片挂载时生效（`:has`）。
  标签若被改名，那一行会自己回来，不会留下空位。
- 客户端 `inject` 依赖 `remote` / `remote.account` / `layout`（登录与插件入口）。缺任意一个时
  插件停在 pending，卡片不出现——与内置账户启动器的依赖一致。

## 目录

```
index.js            宿主：注册唯一路由，按最新激活的 reader 服务
lib/balance.js      凭据解析 + /user/balance + 缓存
lib/routes.js       一条精确 JSON 路由
client.js           客户端：遮蔽 settings.launcher 的卡片
locale/{zh,en}.json 插件页标题/描述
test/wiring.mjs     宿主接线测试（一次注册、重载换实现、释放后重建）
```

自测：`node test/wiring.mjs`。
