# DeepSeek 余额卡片

用已配置的 DeepSeek API Key 读取账户余额，显示在侧栏底部，替代原来的
`··· 更多` 账户入口。设置、插件、登录都在同一张卡片上，余额不需要登录。

## 卡片内容

```
余额                    登录  ✿  ⚙
¥1,741.77
```

- **余额**：宿主侧解析 `DEEPSEEK_API_KEY`，请求 `/user/balance`，缓存 60 秒后由一条 JSON 路由
  （`/dsh-balance/v1/balance`）交给卡片。Key 不进浏览器。
- **登录**：次要文字按钮，走内置授权流程；网页版预开标签页，桌面版由主进程开窗。已登录后
  变成账户入口。
- **插件（✿）**：打开插件面板，并隐藏侧栏顶部那一行「插件」。
- **更多（⋯）**：弹出面板列表（自动化任务、上下文洞察……），并隐藏顶部那一行「更多」；菜单项读实时注册。
- **设置（⚙）**：打开设置面板；`Cmd+,` 仍由内置 Settings 处理。

## 状态

| 状态 | 表现 |
|---|---|
| 正常 | 金额 |
| 余额低于 1 | 金额 warn 色 +「余额不足」 |
| 未配置 Key | 「未配置 API Key」+「去设置」，不显示 0 |
| 读取失败 | 有旧值保留旧金额 +「重试」，否则「暂时读不到余额」 |
| 折叠态 | 36px 卡片图标 + 状态点，金额在 tooltip |

## 限制

- 余额接口只返回总额 / 赠送 / 充值三项，没有按天按月的消费金额，因此卡片不显示也不估算消费。
- 隐藏顶部「插件」行依据当前 8 种语言的标签匹配，只在卡片挂载时生效；标签改名后那行会自己回来。
- 停用或移除本插件后，原账户启动器原样回来，无状态需要迁移。
